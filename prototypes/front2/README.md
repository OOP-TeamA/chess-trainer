# 프2 개인 학습 화면 프로토타입

11주차 개인 개발 진척 공유용 Java Swing 프로토타입입니다. 팀 공용 앱과 별도로 실행하며, 공용 Main·Gradle·백엔드 파일을 수정하지 않습니다.

## 실행

팀 개발 기준은 Java 25입니다. 이 독립 프로토타입 소스는 JDK 17 이상에서 실행할 수 있습니다.

Windows에서는 이 폴더의 `run.bat`을 더블 클릭하거나 저장소 루트에서 다음을 실행합니다.

```powershell
.\prototypes\front2\run.bat
```

macOS/Linux에서는 저장소 루트에서 `bash prototypes/front2/run.sh`를 실행합니다. 컴파일 결과는 이 폴더의 `build/`에 생기며 Git에서 제외됩니다.

## 현재 구현한 화면과 동작

| 화면 | 구현 내용 |
| --- | --- |
| 레슨 | 6개 레슨의 3단계 설명, 이전·다음 이동, 완료 체크 |
| 용어 퀴즈 | 4지선다 10문제, 선택 직후 정답·해설, 결과·다시 풀기 |
| 퍼즐 | 체스판 클릭 10문제, 지정 목표 수 확인, 힌트·초기화·이전·다음 |
| 오답 노트 | 퀴즈·퍼즐 오답 목록과 해설, 기록 삭제 |

창의 메뉴로 네 화면을 전환할 수 있습니다. 데이터와 기록은 DemoData·DemoState를 사용하는 임시 구현입니다.

## 확인할 순서

1. 레슨 한 개를 마지막 단계까지 진행해 완료 표시를 확인합니다.
2. 용어 퀴즈를 틀리거나 맞혀 보고 선택 잠금, 해설, 다음 문제, 결과와 다시 풀기를 확인합니다.
3. 퍼즐의 기물과 도착 칸을 클릭하고 힌트·초기화를 확인합니다.
4. 오답 노트에 틀린 문제가 나타나고 삭제되는지 확인합니다.

## 디자인 PDF와의 관계

`docs/front2-ui-design-draft.pdf`는 별도로 검토할 디자인 초안이고, 이 폴더는 현재 실행 가능한 개인 구현 진척입니다. 두 자료의 레이아웃·예시 문항·문항 수에는 차이가 있습니다. PDF의 모든 화면이 이 프로토타입에 구현됐다는 의미는 아닙니다.

## 구현 범위와 남은 작업

- 현재 레슨은 설명을 읽고 완료하는 방식입니다. 공용 보드 입력과 규칙 기반 레슨 채점은 후속 연결 작업입니다.
- 퍼즐은 지정된 출발·도착 칸과 일치하는지 확인합니다. 전체 합법 수 검사와 다중 수순 퍼즐 채점은 구현하지 않았습니다.
- 퀴즈 정답은 임시 데이터에 들어 있으며 백프의 TermQuizSession을 아직 사용하지 않습니다.
- 완료·오답 기록은 메모리에만 남고 종료하면 초기화됩니다. Progress·ProgressStore·WrongNoteManager 연결은 후속 작업입니다.
- 팀 콘텐츠 파일 형식·용어 ID 및 공용 BoardPanel·Theme·화면 전환은 후속 통합 때 맞춥니다.
- 학습·퍼즐 예시는 시연용이며 최종 콘텐츠 검수는 남아 있습니다.

## 준비 시 확인

Java 17 문법 수준의 ECJ 컴파일러와 JRE 17로 소스를 컴파일했습니다. 창 자체의 최종 실행 확인은 제출자의 PC에서 `run.bat`으로 진행합니다. 이 폴더는 Gradle app 소스 경로 밖에 있어 팀 앱의 컴파일 대상에 포함되지 않습니다.
